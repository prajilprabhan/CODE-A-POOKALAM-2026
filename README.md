## 🎨 My Pookalam

### Description
This digital Pookalam was created during the Onam season using Python and the `joy` vector graphics library. It translates traditional floral design concepts into modular, reusable geometric components:
- **Outer Ring**: Concentric circles in bright yellow, green, and white, adorned with 40 red flower buds (`#d6203b`).
- **Middle Border**: An outer ring featuring 18 repeating overlapping circular patterns with white and violet outlines.
- **Concentric Petals**: A 20-fold repeating geometric star-shaped polygon pattern in vibrant orange and red.
- **Center Piece**: A stylized traditional **Onattappan** (consisting of 3 brown clay pyramid structures) placed at the center of the design.

### Preview
![My Pookalam](output/pookalam-preview.svg)

### Features
- Modular design architecture using custom coordinate points and polygons.
- Clean concentric rotation transformations (`repeat`, `rotate`, `scale`, and `translate`).
- Traditional representation of Onattappan clay figures.
